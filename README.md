#  Pradnesh Painting

A little virtual museum for my projects! Each painting on the museum wall represents a project. Click on a painting to explore it and read its description.

##  What's Inside the Museum?

The museum currently features three projects:

### 1. Entering-Dimension
My first website, marking my journey into web development.

### 2. Repossessed
A mummy-themed side-scroller game.

### 3. Receipt Challenge
A Bad Piggies-themed receipt generator made using p5.js.

The museum also includes a few blank paintings for future projects!

## How It Works

The museum wall is built using a single background image, with invisible clickable buttons positioned over each painting.

- Responsive positioning: Button positions and sizes are defined using percentages (`%`), helping them stay aligned with the paintings across different screen sizes.
- Interactive paintings:Clicking a painting displays its project description underneath the museum wall.
- Expandable collection: Blank paintings leave room for adding more projects in the future.
